# Rekha Stories (रेखा)

Demo website for **Rekha**, a short-form story series: familiar fables drawn as one continuous line, with an ending for today.

- `index.html` is the whole site (no build step)
- `ep01.mp4` and `ep01-poster.jpg` are Episode 1, *The Thirsty Crow*

Served with GitHub Pages from the `main` branch root.
